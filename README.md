# DecodeLabs-Internship
# Week 1 

## Overview

This project was developed as part of the Week 1 assignment. The objective was to design and build a modern, responsive portfolio website using HTML, CSS, and JavaScript.

The website demonstrates the implementation of common portfolio sections, including navigation, hero banner, about section, skills showcase, projects display, and contact information. The content used in the project is for demonstration purposes only.

## Features

* Responsive website layout
* Modern navigation bar
* Hero section with call-to-action buttons
* About section
* Skills showcase cards
* Projects section
* Contact section with social links
* Mobile navigation menu
* Dynamic footer year using JavaScript
* Semantic and accessible HTML structure

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts

## Learning Outcomes

Through this project, the following concepts were practiced:

* Semantic HTML structure
* Responsive web design
* CSS Flexbox and Grid layouts
* Modern UI design principles
* Accessibility best practices
* Basic JavaScript DOM manipulation
* Website organization and component-based design
