# Responsive Webpage Design

## Overview

This project was developed as part of the **DecodeLabs Internship Program – Week 2 Assignment**. The objective was to build a fully responsive webpage that adapts seamlessly across different screen sizes while maintaining proper spacing, alignment, and usability.

The website demonstrates modern front-end development techniques using HTML, CSS, and JavaScript, with a focus on responsive design principles.

## Features

* Responsive navigation bar
* Mobile-friendly hamburger menu
* Hero section with call-to-action
* About section
* Services/Features section
* Contact form
* Footer section
* Smooth scrolling navigation
* Responsive layouts using Flexbox and CSS Grid
* CSS Media Queries for different screen sizes
* Modern and clean user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## Responsive Design Implementation

The website is designed using a mobile-first approach and includes breakpoints for:

| Device Type | Screen Width     |
| ----------- | ---------------- |
| Mobile      | Up to 767px      |
| Tablet      | 768px – 1024px   |
| Desktop     | 1025px and above |

Key responsive techniques used:

* CSS Media Queries
* Flexible Grid Layouts
* Flexbox Containers
* Responsive Navigation Menu
* Adaptive Typography
* Responsive Images
* Consistent Spacing and Alignment
