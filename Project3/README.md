# Project 3 - Interactive Web Elements (HTML/CSS/JS)

A modern, responsive single-page project demonstrating DOM manipulation, real-time updates, and user interaction using **vanilla JavaScript**.

## Features

### 1) Dark Mode Toggle
- Switches between light and dark themes
- Smooth transition
- Saves preference using `localStorage`

### 2) Interactive Counter
- Increment / decrement / reset
- Prevents negative values

### 3) Live Character Counter
- Textarea input
- Shows remaining characters in real time

### 4) Dynamic Quote Generator
- Random inspirational quote from an array
- Smooth fade animation on change

### 5) Interactive FAQ Section
- Expand / collapse answers
- Only one FAQ item open at a time

### 6) Contact Form
- Name, email, message fields
- Client-side validation
- Success message shown without page refresh

## File Structure
- `index.html`
- `Style.css`
- `script.js`
- `README.md`

## How to Run
1. Open `Project3/index.html` in a browser.
2. (Optional) Use Live Server in VSCode for best results.

## JavaScript Concepts Demonstrated
- `querySelector()`
- `addEventListener()`
- `classList.toggle()`
- `textContent` / `hidden`
- Arrays + random selection
- Form validation + preventing refresh
- `localStorage`
